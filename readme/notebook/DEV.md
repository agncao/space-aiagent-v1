# DEV.md — 开发参考

## 我遇到的问题

1. 比如换了 glm 它会并发调用同一工具 parallel_tool_calls，一个工具是向列表增加数据一个工具向列表删除数据，导致异常，请看llm.py #19行的注释

2. AgentResponse ToolStrategy 在有些模型会出错，因为使用它时需要关闭推理模式，然后有些模型不支持关闭推理模型，比如 qwen3.7-preview

3. 幻觉：智能体会推荐一些自己没有的能力，比如月球探测轨道分析，然后我就顺着它的推荐对话，智能体就会一本正经的胡说八道了
4. 写了个添加实体的技能，但在第二轮 entity-agent 没有重新读取 Skill，也没有调用 add_point_entity，却返回了成功，属于“跨轮技能规则丢失 + 成功幻觉”。
