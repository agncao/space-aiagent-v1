## 两行根数（TLE）格式说明

TLE（Two-Line Element Set）是 NORAD 标准格式，用于描述地球轨道物体的轨道参数。

### 格式结构

**Line 1:**

| 字段 | 列号 | 含义 |
|------|------|------|
| Line No. | 1 | 行号固定为 1 |
| Satellite No. | 3-7 | NORAD 卫星编号 |
| Classification | 8 | 密级（U=公开） |
| Intl Designator | 10-17 | 国际编号（年份-编号-部件） |
| Epoch | 19-32 | 历元时间（年份+天内小数） |
| Mean Motion 1st Derivative | 34-43 | 平均运动一阶导数（rev/day²） |
| Mean Motion 2nd Derivative | 45-52 | 平均运动二阶导数 |
| B* Drag | 54-61 | 阻力系数 |
| Ephemeris Type | 63 | 星历类型 |
| Element Set No. | 65-68 | 轨道根数组编号 |
| Checksum | 69 | 校验和（mod 10） |

**Line 2:**

| 字段 | 列号 | 含义 |
|------|------|------|
| Line No. | 1 | 行号固定为 2 |
| Satellite No. | 3-7 | NORAD 卫星编号 |
| Inclination | 9-16 | 轨道倾角（度） |
| RAAN | 18-25 | 升交点赤经（度） |
| Eccentricity | 27-33 | 离心率（小数点省略） |
| Arg of Perigee | 35-42 | 近地点幅角（度） |
| Mean Anomaly | 44-51 | 平近点角（度） |
| Mean Motion | 53-63 | 平均运动（rev/day） |
| Rev at Epoch | 64-68 | 历元圈号 |
| Checksum | 69 | 校验和（mod 10） |

### 示例

```
1 25544U 98067A   08264.51782528 -.00002182  00000-0 -11606-4 0  2927
2 25544  51.6416 247.4627 0006703 130.5360 325.0288 15.72125391563537
```

### 注意事项

- 每行固定 69 个字符
- 校验和为该行所有数字字符（不含行号和校验位本身）之和对 10 取模
- 离心率字段省略前导小数点（如 0006703 表示 0.0006703）
- 平均运动单位为 rev/day（圈/天）
- 历元时间格式为年份后两位 + 年内天数的小数（如 08264.51782528 表示 2008 年第 264 天）

## 场景

航天分析平台几乎所有的操作都基于场景，因此要执行某一行为一定存在一个已经打开的场景

### 实例

1. 删除场景，一定是删除已经当前打开的场景
2. 查询实体，一定是查询当前打开的场景中的实体
3. 创建实体，一定是在当前打开的场景中创建实体
